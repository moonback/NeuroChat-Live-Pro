# 🗺️ Roadmap - NeuroChat Live Pro

Feuille de route pour l'évolution de NeuroChat Pro d'un assistant conversationnel vers un agent autonome complet.

---

## ✅ Phase 1 : Fondations (MVP) - Terminée
- [x] **Conversations vocales temps réel** avec Gemini Live.
- [x] **Vision multimodale** (Caméra + Partage d'écran).
- [x] **Navigation Web Autonome** (Playwright integration).
- [x] **Contrôle Système** (Commandes terminal).
- [x] **Personnalité Unique Focus** : Optimisation de NeuroChat Pro.
- [x] **Gestion de Documents** (PDF/TXT context).
- [x] **Interface Premium** : Design immersif et animations.

---

## 🚀 Phase 2 : Intelligence & Mémoire (En cours)
- [ ] **Persistance de Session** : Sauvegarde automatique de l'historique complet.
- [ ] **Vector Memory (RAG)** : Utilisation d'un vector store local pour une mémoire à long terme (recherche dans les documents passés).
- [ ] **Éditeur de Fichiers Personnalité** : Interface pour éditer directement `SOUL.md`, `USER.md` et `MEMORY.md`.
- [ ] **OCR Avancé** : Meilleure extraction de texte pour les captures d'écran et PDF complexes.
- [ ] **Multi-Format** : Support des fichiers Word (.docx) et Excel (.xlsx).

---

## 🛠️ Phase 3 : Plugins & Écosystème (Prévue - Q3 2025)
- [ ] **Marketplace d'Outils** : Permettre d'ajouter des outils tiers (APIs météo, news, crypto, etc.).
- [ ] **Automation Workflows** : Création de macros vocales ("Neuro, prépare ma réunion de demain").
- [ ] **Mode Collaboration** : Partage d'une session avec un autre utilisateur via WebRTC.
- [ ] **Voice Cloning** : Possibilité d'utiliser des voix personnalisées via des services de TTS tiers.

---

## 🔮 Phase 4 : Agent de Système Total (Vision 2026)
- [x] **Deep OS Integration** : Contrôle natif des fenêtres et des fichiers sans passer par le terminal.
- [ ] **Self-Correction** : Capacité de l'IA à déboguer ses propres appels d'outils.
- [ ] **Mobile Companion** : Application mobile connectée à l'instance Desktop pour un usage en mobilité.
- [ ] **Compétenes Spécialisées** : Modules de compétences téléchargeables (Codeur Expert, Analyste Financier, Coach Santé).

---

## 📈 Objectifs de Performance
- **Latence Vocale** : Maintenir < 150ms pour une sensation de conversation humaine.
- **Précision Vision** : Analyse de 2 frames par seconde sans impacter les performances CPU.
- **Fiabilité Outils** : Taux de succès des appels de fonction > 95%.
